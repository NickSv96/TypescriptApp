# 📱 App React Native con Expo:

Esta es una aplicación básica desarrollada con **React Native** y **Expo**, estructurada con una pagina principal que muestra el título "Mis Tareas" y una serie de tarjetas con detalles de las tareas añadidas, al presionar las tareas se abre una un contenedor el cual muestra mas detalles de las tareas junto con un boton para retroceder a la pantalla inicial.

---

## 🚀 Requisitos previos:

Antes de comenzar, asegurate de tener instalado:

- **Node.js** (versión LTS recomendada): [Descargar Node.js](https://nodejs.org/)
- **npm** (incluido con Node.js)
- **Expo Go**: Descargá la aplicación en tu celular desde Google Play Store (Android) o App Store (iOS).

---

## 🛠️ Pasos para ejecutar la aplicación:

### 1. Clonar el repositorio e instalar dependencias:

Abrí la terminal en la carpeta del proyecto y ejecutá:

```bash
npm install
```

y para iniciar el server

```bash
npx expo start
```

### 📱 Visualización en dispositivo o emulador

Una vez iniciado el servidor:

### Dispositivo móvil (Recomendado):

Android: Abrí la app Expo Go y escaneá el código QR que aparece en la terminal.

iOS: Abrí la cámara del celular, escaneá el código QR y abrilo en Expo Go.
(Nota: El celular y la computadora deben estar conectados a la misma red Wi-Fi).

### Emulador:

Presioná a en la terminal para abrir en un emulador de Android.
Presioná i en la terminal para abrir en el simulador de iOS (disponible solo en macOS).
